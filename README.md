# ⚽ Футбольный Менеджер

Простой многопользовательский футбольный менеджер для тебя и друзей.

## Что умеет

- Регистрация и вход
- Создание своей команды + автоматическая генерация состава
- Лига с турнирной таблицей
- Товарищеские матчи
- Трансферный рынок (выставлять и покупать игроков)
- Админ-панель (просмотр пользователей, запуск туров)

## Как запустить (на своём компьютере)

### 1. Установи Node.js
Скачай с https://nodejs.org (версия 18 или новее)

### 2. Открой папку проекта в терминале
```bash
cd football-manager
```

### 3. Установи зависимости
```bash
npm install
```

### 4. Запусти
```bash
npm start
```

Сайт откроется по адресу: **http://localhost:3000**

### Данные для входа админа
- Логин: `admin`
- Пароль: `admin123`

## Как сделать так, чтобы друзья могли зайти

Есть несколько бесплатных вариантов:

### Вариант 1 — Ngrok (самый быстрый)
1. Запусти сайт у себя (`npm start`)
2. Установи ngrok: https://ngrok.com
3. Выполни: `ngrok http 3000`
4. Получишь ссылку вида `https://xxxx.ngrok.io` — её и кидай друзьям

### Вариант 2 — Railway / Render (постоянный хостинг)
1. Зарегистрируйся на https://railway.app или https://render.com
2. Создай новый проект → Deploy from local / GitHub
3. Укажи команду запуска: `npm start`
4. Получишь постоянную ссылку

### Вариант 3 — VPS
Любой дешёвый VPS (Timeweb, FirstVDS, DigitalOcean и т.д.) + `pm2` или `systemd`.
